# Полезные функции — анализ и приоритет

Семья: 2 взрослых + ребёнок, batch 2–7 дней, облако, лимит 50–80к.

## Сейчас внедряем (этот релиз)

| Функция | Зачем |
|---------|--------|
| **Рецепт → в план** | Выбрал блюдо → указал людей / порции / дни / приём пищи → слоты ближайших дней заполняются |
| **Масштаб ингредиентов в карточке** | Сразу видно закупку под выбранные порции |
| **Редизайн** | Уйти от Bootstrap-зелёного «AI slop» к своему визуальному языку |

## Следующая волна (P0/P1)

| Функция | Зачем |
|---------|--------|
| Корзина только из выбранных слотов / «докупить под это блюдо» | Не тащить всю неделю, если добавили одно |
| Таймлайн большой готовки | Уложиться в час жены |
| Разогрев vs новая варка цветом в плане | Понятно, что уже сварено |
| Быстрая замена с сохранением порций/дней | Жена дизлайкнула — не сбрасывать масштаб |
| Морозилка / зоны запасов | Парное мясо крупными партиями |
| Рейд Молоково (только белок) | Отдельный список на самовывоз |
| Срыв плана → ужин 20 мин | Реальность с ребёнком |
| Прогноз ₽ недели после правок плана | Контроль бюджета в момент выбора |
| Любимое / запретить на месяц | Персонализация без настроек-ада |
| Детская порция отдельно в масштабе | 3 взрослых-эквивалента ≠ 2+1 ребёнок |

## UX-принципы редизайна

- Кухня: крупные зоны, мало хрома, читается с метра  
- Командный: плотнее, цифры и план  
- Бренд «Семейная кухня» — заметный якорь, не зелёная Bootstrap-шапка  
- Без фиолетовых градиентов, без «карточного ада» одинаковых shadow-sm
