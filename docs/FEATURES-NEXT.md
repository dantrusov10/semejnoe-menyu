## Как сделать LLM-замены

1. Уже есть `suggestReplacements()` — shortlist 5–6 блюд того же типа/белка/цены.  
2. Поверх: Worker-эндпоинт `POST /suggest` с контекстом (текущее блюдо, shortlist, запасы, запреты ребёнка).  
3. Модель только **переранжирует/поясняет** shortlist, не выдумывает продукты вне каталога.  
4. В UI: кнопка «Умная замена» уже показывает скорер; подпись от LLM можно добавить вторым шагом без ломки UX.  
5. Стоимость: кэш по `dishId + week`, лимит запросов на семью.
