# Семейная кухня

**Онлайн:** https://dantrusov10.github.io/semejnoe-menyu/  
**Репозиторий:** https://github.com/dantrusov10/semejnoe-menyu

ОС домашней еды для семьи из трёх (Богданиха): запасы → меню → корзина → готовка → деньги.  
Магазины: Ашан, Пятёрочка, [Парное мясо](https://parnoemjaso.ru/) (Молоково).

## Что умеет MVP

- Два профиля UI: **Кухня** (жена/дежурный) и **Командный центр**
- **Сегодня** — меню дня, рецепт, замена ужина в один тап
- **План** — авточерновик недели из 12 шаблонов + batch-подсказки
- **Запасы** — ввод остатков + умный подбор блюд (strict / almost)
- **Корзина** — план × порции − запасы → списки по магазинам + копирование
- **Рецепты** — развесовка, шаги, детский блок, цена партии
- **Бюджет** — готовка / вино / джин / вкусняшки
- Состояние в **IndexedDB**, экспорт/импорт JSON

Открой `index.html` через любой static server (модули ES) или пользуйся GitHub Pages.

Пересборка каталога блюд/цен:

```bash
node tools/build.mjs
```
