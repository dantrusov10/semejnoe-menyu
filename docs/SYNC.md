# Общие запасы между телефонами

Синхронизация через **private GitHub Gist** (уже создан для семьи).

## Один раз на каждом телефоне

1. Откройте https://dantrusov10.github.io/semejnoe-menyu/ → **Синхрон**
2. Создайте токен: https://github.com/settings/tokens → **Generate new token (classic)**
3. Права: только **`gist`**
4. Вставьте токен в приложение → **Сохранить токен** → **Забрать из облака**

Тот же токен (или отдельный classic с `gist`) вставьте на втором телефоне.

## Как это работает

- Остатки и события (покупки / готовка) пишутся в gist `family-sync.json`
- Приложение подтягивает облако при открытии, каждые ~25 сек и при возврате на экран
- Локально всё кэшируется в IndexedDB (офлайн-чтение)
