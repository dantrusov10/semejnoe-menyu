# Семейное меню (семья из 3)

**Онлайн:** https://dantrusov10.github.io/semejnoe-menyu/  
**Репозиторий:** https://github.com/dantrusov10/semejnoe-menyu

Планировщик питания на 3 месяца: магазины Пятёрочка / Ашан / [Парное мясо](https://parnoemjaso.ru/), деревня Богданиха (МО, Ленинский р-н). Полный бюджет еды+алко+вкусняшки 50–80к.

## Цель продукта (HTML)

1. Выбор блюд → рецепты с развесовкой, где купить, ориентир по цене.
2. Обратный режим: какие продукты есть → на какие блюда хватает и на сколько порций.
3. Меню без повторов блюд на 3 месяца, batch-cook, минимум возни.
