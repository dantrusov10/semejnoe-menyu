# Семейное меню (семья из 3)

Планировщик питания на 3 месяца: бюджет ≤ 20 000 ₽/мес, магазины Пятёрочка / Ашан / [Парное мясо](https://parnoemjaso.ru/), деревня Богданиха (МО, Ленинский р-н).

## Цель продукта (HTML)

1. Выбор блюд → рецепты с развесовкой, где купить, ориентир по цене.
2. Обратный режим: какие продукты есть → на какие блюда хватает и на сколько порций.
3. Меню без повторов блюд на 3 месяца, batch-cook, минимум возни.
